# 💌 카카오페이 AI 마음 계산기 (Maum AI)

**관계의 데이터를 해석하여 마음의 무게를 정량화하다**

---

## 1. 프로젝트 개요 (Overview)

### 📌 배경 및 문제 정의 (Pain Point)

경조사비 결정은 현대인에게 큰 심리적 스트레스와 의사결정 피로감을 줍니다.  
“너무 적게 내서 관계가 소원해지면 어떡하지?”  
“너무 과하게 지출하는 것은 아닐까?”  

이러한 고민은 **관계의 불확실성**에서 비롯됩니다.

### 💡 솔루션 (Solution)

**Maum AI**는 카카오톡의 **비정형 대화 데이터**와 카카오페이의 **정형 송금 데이터**를 결합한  
**AI 관계 가치 평가 엔진**입니다.

데이터 기반의 객관적 지표를 통해 **최적의 경조사비를 산출**하고,  
**실제 송금 서비스까지 즉시 연결**합니다.

---

## 2. 핵심 기능 (Key Features)

### 📊 하이브리드 데이터 분석

- **정량 분석**
  - 과거 송금 내역(상호 부조 패턴)
  - 최근 교류 빈도

- **정성 분석**
  - LLM 기반 대화 맥락, 어조, 친밀도 분석

- **외부 변수 반영**
  - 실시간 예식장 식대 (위치 기반)
  - 물가 상승률(CPI) 자동 반영

### 🎯 상황별 맞춤 솔루션

- **유형 1: 친밀도 높음**
  - 개인화된 최적 금액 제안
  - AI 기반 축하 메시지 자동 생성

- **유형 2: 친밀도 낮음**
  - 경제적 부담 완화를 위한 **함께 보내기(Group Pay)** 기능 연동

## 3. 서비스 로직 및 UX 플로우

### 🔍 AI 다차원 친밀도 분석 지표

| 지표 | 세부 분석 내용 | 판단 근거 예시 |
|---|---|---|
| 언어적 거리감 | 높임말 / 반말 비율 | 높임말 90% 이상 시 의례적 관계 |
| 정서적 밀도 | 감정 표현, 이모티콘 | 친근한 수식어·이모티콘 혼재 시 유대감 높음 |
| 상호 교류 균형 | 대화량 밸런스 | 일방적 질문·단답 반복 여부 |
| 주제의 깊이 | 사적 vs 공적 | 개인적 고민·일상 공유 빈도 |

## 4. 기술 전략 (Technical Strategy)

### 🤖 AI Pipeline & Prompt Engineering

- **LLM Persona**
  - *20년 경력의 인간관계 상담사* 페르소나 적용

- **Chain of Thought (CoT)**
  - 맥락 분석 → 근거 추론 → 점수 도출

- **Structured Output**
  - JSON 출력 강제 → UI 컴포넌트(레이더 차트 등) 연동

### 🛡 보안 및 성능 최적화

- **On-device AI (Privacy First)**
  - 대화 내역 로컬 분석 후 즉시 파기

- **RAG (Retrieval-Augmented Generation)**
  - 실시간 식대·물가 지표 조회
  - 할루시네이션 방지

- **Function Calling**
  - 산술 계산은 API로 분리하여 무결성 확보
